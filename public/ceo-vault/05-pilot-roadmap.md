# 90-Day Digital Dalasi Pilot

## Pilot Scope
| Parameter | Value |
|-----------|-------|
| Duration | 90 days |
| User Cohort | 10,000 civil servants |
| Geography | Banjul + Kanifing Municipal Council |
| Budget | D5M (~$100,000) |
| Funding | Development partner grant |
| Government Cost | D0 |

## Week-by-Week Roadmap
| Weeks | Activities | Deliverables |
|-------|------------|--------------|
| 1–2 | Deploy sovereign cloud sandbox | Dev environment live |
| 3–4 | Configure identity layer (MOSIP) | Identity system ready |
| 5–6 | Integrate with two commercial banks | Payment gateway live |
| 7–8 | Enroll first 5,000 civil servants | 5,000 IDs issued |
| 9–10 | Process salary payments digitally | 2,500 payments processed |
| 11–12 | Launch digital business license pilot | 1,000 licenses issued |
| 13 | Pilot review + report | Full report delivered |

## Success Metrics
| KPI | Target | Measurement Method |
|-----|--------|--------------------|
| IDs issued | 10,000 | System dashboard |
| Salary payments processed | 5,000 | Gateway transaction log |
| Digital licenses issued | 1,000 | Registry system |
| System uptime | 99.9% | Monitoring dashboard |
| Average response time | <2 seconds | APM tools |
| User satisfaction | >80% | Exit survey |
| Cost per transaction | <D2 | Financial reconciliation |

## Pilot Dependencies
| Dependency | Owner | Risk if Delayed |
|------------|-------|-----------------|
| Presidential directive | Government | Pilot blocked |
| Two bank integrations | Banks + FORTIS | Payment module delayed |
| Civil servant roster | Ministry of Finance | Enrollment delayed |
| Biometric hardware | FORTIS INVICTA | Identity module delayed |
| Network connectivity | GAMTEL/GTIG | System performance risk |

## Post-Pilot Scaling Path
1. **Month 4:** All civil servants (25,000) enrolled
2. **Month 6:** Extend to teachers + health workers
3. **Year 1 End:** 100,000 citizens enrolled
4. **Year 3:** 500,000 citizens (25% of population)
5. **Year 5:** 2M citizens (80% of adult population)
